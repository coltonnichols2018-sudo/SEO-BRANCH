# Image Alt Text & File Naming Guide
## Bubba's Mattress & Furniture

---

## WHY THIS MATTERS

Google can't "see" images — it relies on alt text and file names to understand what's in a photo. Proper image SEO helps your products show up in Google Image Search, which drives additional traffic to your site.

---

## FILE NAMING RULES

BEFORE uploading any image to Shopify, rename the file using this format:

**Format:** `[brand]-[product-type]-[detail]-louisville-ky.[extension]`

### Examples:
| Bad File Name | Good File Name |
|---------------|----------------|
| IMG_4532.jpg | ashley-queen-memory-foam-mattress-louisville.jpg |
| photo1.png | ashley-power-recliner-brown-leather-louisville.jpg |
| 20240315_102233.jpg | ashley-sectional-sofa-gray-fabric-louisville.jpg |
| download.jpg | bubbas-furniture-store-showroom-louisville-ky.jpg |
| product-image.webp | ashley-bedroom-set-dark-brown-louisville.jpg |

## HOW TO ADD ALT TEXT IN SHOPIFY

### For Product Images:
1. Go to Shopify Admin > Products
2. Click on a product
3. Click on the product image
4. In the "Alt text" field, enter your descriptive alt text
5. Click "Save"

### For Theme/Section Images:
1. Go to Online Store > Themes > Customize
2. Click on any image section
3. Look for "Image alt text" field
4. Enter your descriptive alt text
5. Click "Save"

### For Blog Post Images:
1. When adding an image to a blog post
2. Click on the image after inserting
3. Click the "Alt text" option
4. Enter your descriptive alt text

## IMAGE OPTIMIZATION CHECKLIST

- [ ] Every image has a descriptive file name (not IMG_xxxx)
- [ ] Every image has alt text that includes product name + "Louisville KY"
- [ ] Images are compressed (under 200KB for product photos, under 500KB for banners)
- [ ] Images are the correct dimensions (don't upload 4000px images for thumbnails)
- [ ] Use JPEG for photos, PNG for logos/graphics with transparency
- [ ] Consider WebP format for faster loading (Shopify handles this automatically in newer themes)
