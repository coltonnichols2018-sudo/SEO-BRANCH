## ON-PAGE SEO CHECKLIST FOR EVERY PAGE

- [ ] Unique, keyword-rich title tag (under 60 characters)
- [ ] Compelling meta description with CTA (under 155 characters)
- [ ] One H1 tag per page with primary keyword
- [ ] H2/H3 subheadings with secondary keywords
- [ ] First paragraph includes primary keyword naturally
- [ ] Internal links to related collections/products (3-5 per page)
- [ ] All images have descriptive alt text with location keywords
- [ ] URL is short and keyword-friendly
- [ ] Phone number is clickable (tel: link)
- [ ] Address appears on every page (footer)
- [ ] Page loads in under 3 seconds
- [ ] Content is 300+ words for collection pages, 800+ for blogs
